# Project Instructions

## Project
Technical Debt Intelligence & Governance PoC.

## Core Principles
- Signal is not Technical Debt.
- AI proposes, evidence explains, human decides.
- Prefer clear code over clever code.
- Do not implement functionality outside the requested scope.
- Do not introduce unnecessary abstractions.
- Do not add frontend code until the frontend technology is decided.

## Development
- Use clear and domain-oriented names.
- Keep changes small and focused.
- Add tests for changed behavior.
- Do not refactor unrelated code.
- Do not hard-code secrets, IP addresses, connection strings, or model names.

## Workflow
Before implementing:
1. Inspect the existing code.
2. Understand the requested scope.
3. Change only the necessary files.
4. Run relevant tests.
5. Explain what changed and why.
